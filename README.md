# Stackly — AI-Powered Cybersecurity Platform

A premium, full-featured cybersecurity platform website inspired by AVG, Avast, and McAfee. Built with vanilla HTML, CSS, and JavaScript.

---

## 🚀 Features

- **AI-powered real-time threat protection** with BrainShield AI Engine
- **Animated splash screen** with loading progress bar
- **Live threat ticker** scrolling real-time threat data
- **Hero section** with typewriter animation, particle canvas, glassmorphic switcher, and slide backgrounds
- **Interactive Orbit section** — hover-activated threat nodes orbiting an AI core
- **Live security dashboard mockup** with animated charts and threat logs
- **Testimonials carousel** — infinite auto-scroll with user reviews
- **Pricing tiers** — Free, Pro, and Ultimate plans
- **Blog section** with categorized posts and author profiles
- **Multi-platform download** — Windows, macOS, Android, iOS, Linux
- **Newsletter signup** and partners ticker
- **Fully responsive** mobile-friendly design with hamburger nav
